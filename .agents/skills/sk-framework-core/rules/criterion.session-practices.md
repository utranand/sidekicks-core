# criterion.session-practices

Inspect with `sidekicks framework show criterion.session-practices`; toggle with
`sidekicks framework disable criterion.session-practices` or `sidekicks framework enable criterion.session-practices`.
This rule cannot override the consent-gated safety floor in AGENTS.md.

### Session working practices — ten standing defaults

1. **Orient when the task needs the repository.** Use one `sidekicks index show --json` when scope
   is unknown; reuse resolved scope. Align supplied paths before scoped work. External reading and
   ordinary conversation need no repository bootstrap.
2. **Scale effort to stakes.** Delegate when complexity, useful parallel work, or independent
   judgment warrants it. Read `sidekicks framework show criterion.model-tier-substitution` when delegating; local reasoning needs no extra agent.
3. **Batch independent reads.** Sequence dependencies and writes that share state.
4. **Ground claims in evidence.** Apply Rule 5; distinguish observed facts from assumptions.
5. **Verify consequential deliveries independently.** Check the real artifact or behavior beyond
   the executor's report. Small reversible edits need proportionate local checks.
6. **Challenge high-stakes findings.** Attempt to refute them before reporting.
7. **Report outcome first.** Include failed/skipped checks and remaining work; suggest next steps
   only when useful work remains.
8. **Load memory by operation.** Use the relevant category map and packs; query a specific entry
   when needed. Read every hard rule in a triggered category. Record durable decisions only.
9. **Choose workflow by `sidekicks framework show rule.plan-first`.** Use resumable queues for work that benefits from
   resumption, not merely because the user says “finish” or “keep going.”
10. **Verify in proportion to the change.** Run affected checks during iteration and the required
    integration gate at handoff. Reuse passing evidence until changes or failures invalidate it.
    Report pre-existing failures with evidence; never call an unrun or failed required gate green.
